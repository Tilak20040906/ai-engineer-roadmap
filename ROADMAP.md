# AI Engineer Roadmap

Target pace: 1–2 hours/day, 6 days/week. Timeline is flexible; understanding matters more than speed.

## Stage 1 — Python and data tools (Weeks 1–3)
- Revise functions, classes, collections, exceptions, files, and virtual environments.
- Practise NumPy, pandas, Matplotlib, and notebook workflows.
- Deliverable: a small exploratory data analysis notebook.

## Stage 2 — Math and statistics (Weeks 2–5, alongside Stage 1)
- Mean/variance, probability, distributions, vectors, matrices, derivatives, gradient descent.
- Deliverable: explain key concepts in your own words with small examples.

## Stage 3 — Machine Learning (Weeks 4–9)
- Train/test split, leakage, regression, classification, trees, random forests, clustering.
- Metrics: accuracy, precision, recall, F1, confusion matrix; cross-validation and overfitting.
- Deliverable: compare at least three models on one dataset.

## Stage 4 — Deep Learning (Weeks 10–13)
- Neural networks, activations, loss, backpropagation, optimizers, CNNs, transfer learning.
- Deliverable: image classifier with a documented evaluation.

## Stage 5 — NLP and Computer Vision (Weeks 14–17)
- NLP: text cleaning, TF-IDF, embeddings, basic text classification.
- Vision: preprocessing, CNNs, transfer learning.
- Deliverable: one small NLP exercise and one vision experiment.

## Stage 6 — Generative AI and LLMs (Weeks 18–21)
- Tokens, context windows, prompts, API calls, structured outputs, tool calling, safety, evaluation.
- Deliverable: a small LLM-powered application. Keep keys in environment variables.

## Stage 7 — RAG and agents (Weeks 22–25)
- Chunking, embeddings, retrieval, vector search, citations, tool use, validation, human approval.
- Deliverable: document Q&A with source references.

## Stage 8 — Deployment and MLOps (Weeks 26–36)
- FastAPI, tests, Docker basics, logging, model/version tracking, evaluation, deployment.
- Deliverable: deployed demo or clear local run instructions plus tests.

## Weekly routine
- 30 minutes: lesson and notes
- 45 minutes: coding independently
- 30 minutes: exercise/project
- 15 minutes: review and learning log

## Definition of done
A topic is complete when I can explain it without notes, implement a small example, test it, and describe limitations.
