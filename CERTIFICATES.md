## LinkedIn checklist
- [ ] Confirm the credential is issued and the name is correct.
- [ ] Copy the official credential/share URL, if available.
- [ ] Add it under LinkedIn → Profile → Add profile section → Recommended → Add licenses & certifications.
- [ ] Enter the exact credential name, issuing organization, issue date, credential ID if provided, and verification URL.
- [ ] Share a short post explaining one thing learned and linking to a related project.
- [ ] Do not describe a course badge as a professional exam certification unless the issuer does so.

## Notes
Google's Machine Learning Crash Course offers module badges for quiz completion; it does not describe itself as a formal certification. Check the provider's current rules before making claims.
